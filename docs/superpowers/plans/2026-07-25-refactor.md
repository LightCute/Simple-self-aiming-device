# 项目重构实现计划

> **For agentic workers:** Use inline execution for this plan.

**Goal:** 将 control.c 拆为 speed_ctrl/angle_turn/line_track 三个 SOLID 模块，main.c 只做调度。

**Architecture:** 每个模块一个 struct + Init/Start/Update 三部曲。通过 `correction` 浮点值协作。

**Tech Stack:** C (STM32 HAL), 复用 PID_Calc/Angle_Error/tracking

## Global Constraints
- BSP 层全部保留不变
- 三个模式：SPEED/ANGLE/TRACK
- KEY3 切换模式，KEY4 启动
- OLED + 串口日志保留

---

### Task 1: SpeedCtrl 模块

Create `Core/speed_ctrl.h` + `Core/speed_ctrl.c`。封装速度闭环：两个 PID，SetTargets 设目标，Update 每10ms读编码器算PID输出电机。内部直接调 TB6612。

### Task 2: AngleTurn 模块

Create `Core/angle_turn.h` + `Core/angle_turn.c`。封装角度转弯：Start(delta) 设目标，Update 每10ms读 MPU6050 算角度PID 输出 correction。角度到位自动 DONE。

### Task 3: LineTrack 模块

Create `Core/line_track.h` + `Core/line_track.c`。封装巡线：Update 每10ms读 tracking 传感器算转向PID 输出 correction + 返回 TrackEvent（直角弯/正常）。

### Task 4: main.c 重写

仅做模式调度：3 个模式 + OLED + 按键。模式 0=SpeedCtrl调试，模式1=AngleTurn调试，模式2=LineTrack巡线。TIM6 ISR 每10ms调对应模块 Update。

### Task 5: 清理

删除 control.c/h、motor_test.c/h 等旧文件。更新 MDK 工程文件。
